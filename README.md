# Planing Hotel

A hotel platform in progress: a public hotel website with online booking, plus an Employee Panel (PMS, Property Management System) for hotel staff.

The frontend is built. The backend is not built yet, so all data is sample data and nothing is saved.

| Part | Path | Status |
| --- | --- | --- |
| Hotel website and Employee Panel | [`hotel-website/`](hotel-website/) | Frontend done, demo data |
| Backend / API | not started | Planned |

## Quick start

Requirements: [Node.js](https://nodejs.org/) 20 or newer.

```bash
cd hotel-website
npm install
npm run dev
```

Then open:

- Hotel website: http://localhost:5173/
- Employee Panel: http://localhost:5173/panel/login (demo login, any username works)

See [`hotel-website/README.md`](hotel-website/README.md) for features, project structure and screenshots.
